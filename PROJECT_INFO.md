# MCP-Intro Project Information

This project, named MCP-Langgraph Integration Tutorial, is designed to demonstrate how to integrate Model Context Protocol (MCP) servers with Langgraph agents for building advanced AI applications with tool-enabled capabilities.

## Key Features:
- Conversational AI agent leveraging GPT-4.1
- Multiple MCP servers providing various functionalities such as filesystem operations, data manipulation, Git and GitHub integration
- Use of Langgraph for orchestrating conversation flow and streaming responses

## Prerequisites:
- Python 3.13+
- Node.js
- Docker
- UV package manager
- OpenAI API key

## Project Structure Highlights:
- scout/: Contains Langgraph agent and client implementation
- my_mcp/: MCP server configurations and custom server implementations

## Extending the Project:
Users can extend the project by adding new MCP servers, modifying system prompts, adding tools, or customizing conversation flows.
